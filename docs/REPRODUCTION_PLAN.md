## 下一阶段：布料定量实验

优先修复旗帜实验发现的材料差异：当前局部主拉伸显著超过论文的 10% 限制，需要实现并验证应变限制，再扩展深层级实验。

1. 保持最粗和最细网格固定，构造 2/4/8/16 个层级，先检查延拓的秩和初始状态相容性。
2. 逐项扫描层数、时间步和材料刚度，区分数值失稳与求解未收敛。
3. 比较连续性、层间一致性及细节；对 VelPro 做一致性权重扫描，保留不符合预期的结果。
4. 增加网格规模，检查当前观察是否只是低分辨率效应。
5. 单独比较当前代理能和各层本征能，评估能量模型对结果的影响。

## 后续：向论文完整布料实现靠近

1. 将优化器升级为适合薄壳的 Newton 型求解，验证局部 Hessian 与可行线搜索。
2. 引入 PSQ 的层级构造与非线性延拓，重点检验低分辨率膜锁定及静止形状保持。
3. 扩展到一般障碍物、连续碰撞检测、自碰撞、摩擦与应变限制，确保安全细化。
4. 再选择布料覆盖障碍物、旗帜等论文场景；大型帽子/气球场景留到此后。

## 复现口径

当前是独立实现的布料研究基线，未取得作者完整代码或场景参数。当前线性延拓不等价于 PSQ，地面屏障不等价于完整 C-IPC；数值趋势必须限定于实际运行配置。稳定性证明的线性或固定非线性修正假设也不能直接推广到任意非线性接触场景。
