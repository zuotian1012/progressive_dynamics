## 对齐范围与依据

核心目标是 PD 2024 / PD++ 2025 的逐层、水平 warm start 动力学分支，采用 PSQ 延拓与预条件器、Neo-Hookean 膜能、离散铰链弯曲、C-IPC 接触和各向同性应变限制。

依据：

- [PD 2024](https://pcs-sim.github.io/pd/)，尤其 §4.6、Algorithm 1；本地 `tmp/pdfs/paper2.txt`。
- [PD++ 2025](https://pcs-sim.github.io/pd%2B%2B/)，§3.1、积分模板、§8.2.3 的一致性势能；本地 `tmp/pdfs/pdpp-readable.txt`。
- [PSQ 2023](https://pcs-sim.github.io/psq/)，§4.3、§4.5、Algorithm 1；本地 `tmp/pdfs/psq.txt`。
- [C-IPC 2021](https://ipc-sim.github.io/C-IPC/file/paper_small.pdf)，§4.1 Eq. (5)–(7)、§5；[作者源码](https://github.com/ipc-sim/Codim-IPC)保存于 `external/Codim-IPC-main`，参考 `Library/FEM/Shell/INEXT.h`、`IMPLICIT_EULER.h`、`BENDING.h`、`DISCRETE_SHELL.h`。
- [libshell](https://github.com/evouga/libshell)，使用截至 2024 年末的提交 `855a07b7955e3f0311230b17daa805e8ddbb7464`，避免用后来新增的模型替换论文引用的模型。
- [Probabilistic Quadrics 作者参考实现](https://github.com/Philip-Trettner/probabilistic-quadrics)，MIT 许可原文件保留于 `external/probabilistic-quadrics-master`。使用其概率平面二次误差公式。

## 本次修正

| 项目 | 旧实现 | 当前实现与依据 |
| --- | --- | --- |
| 应变屏障 | 缺少区间归一化，固定尺度 | 补齐 C-IPC Eq. (5) 的 `(s-s_hat)^-2`，按厚度×面积积分 |
| 应变刚度 | 固定 `1e4` | C-IPC §4.1：初始 1000 Pa，同一元素连续两个已接受 Newton 迭代的间隙小于 `1e-4*(s-s_hat)` 时翻倍，按论文上限截断至 100000 Pa |
| 收敛度量 | 最大坐标分量除以 dt | C-IPC / PSQ：`||p_free||_2/(sqrt(n_free)*dt)`；RMS 与旧最大分量同时记录，夹爪附加自由度仍另行检查 |
| 膜 Hessian | 对解析梯度做中心差分 | 对 `mu F + (lambda log J-mu) F C^-1` 解析求导 |
| 弯曲 Hessian | 对解析梯度做中心差分 | 对有符号二面角梯度精确执行链式求导，无差分步长；逐元素半正定投影仍保留 |
| 弯曲角差 | 将 `theta-theta_rest` 再周期折返 | 按 C-IPC `BENDING.h` 直接使用有符号角之差；旧 periodic 模式仅作对照 |
| 仿射夹爪 Hessian | 数值差分 | 对正交性势能解析求导；夹爪仍为本 demo 扩展，不声称是论文场景 |
| CCD | IPC Toolkit 默认 Tight Inclusion | 显式使用 C-IPC Additive CCD；旧方法可作对照 |
| 默认预条件器 | 衣服命令默认投影细层 Hessian | 所有场景默认当前层 Hessian，匹配 PSQ §4.5；`proxy` 保留为显式消融 |
| 网格简化 | 普通 QSlim | 作者概率平面二次误差 + Liu 等联合自参数化；保留普通模式作回归对照 |
| 初始化检查 | 每层开始时才检查；预处理只检查自交 | 预处理另检查厚度间距，仿真先验证所有层的衣服和实体碰撞几何 |
| 实验溯源 | 部分模型参数隐含 | 显式记录应变模型/刚度/激活阈值、Hessian、角差、收敛度量、CCD；旧模型续算须参数匹配 |

归一化前后不是同一个势能。在旧默认宽度 `s-s_hat=0.05` 下，缺失的因子为 400；同时本次把名义初始刚度从 10000 改为论文的 1000 Pa，所以不能简单说所有应变力都增加 400 倍。刚度变化会改变势能，日志显式记录发生调整的迭代，不能跨调整点要求总势能单调下降。

自适应应变刚度属于每条轨迹的状态：下一时间步继承、断点恢复时从最后已接受步恢复，不会从 VelPro 传到 Direct 对照。达到迭代上限仍判为失败，不作为预览成功。

## 核对后保留的设计

- **冻结 PSQ 偏移求梯度是论文方法**：PD §4.6 明确采用它；位置使用非线性 P，速度使用 U。线搜索评估完整非线性势能。
- **水平 warm start 是论文允许且广泛采用的分支**：PD Algorithm 1 第 12 行及 §4.6。没有实现安全边展开，不代表这个分支缺少每步必须调用的步骤。
- **质量加权一致性项**：保持 `w*(x-P_lower x_lower_next)^T M*(x-P_lower x_lower_next)`，与 PD++ §8.2.3 对齐，梯度中的 `2w` 没有省略。
- **膜能与二维 Lamé 系数**：与 libshell 的第一基本形式表达式核对一致，不换成三维平面应变参数。
- **弯曲系数**：`k=E*t^3/[24*(1-nu^2)]`、`edge_length/hbar` 与 C-IPC 离散铰链一致；当前代码用等价的 `0.5*kb*weight` 表达。
- **接触厚度屏障**：IPC Toolkit 当前调用已实现 `distance^2-dmin^2` 与 `dhat^2+2*dhat*dmin` 的 C-IPC 偏移，已补独立公式测试；不再笼统称其为“没有 C-IPC 厚度模型”。碰撞集合显式设置为 IPC、无面积加权。
- **摩擦**：每时间步滞后一次，符合 C-IPC 文中实验设置。衣服没有夹爪绑定、固定抓取点或位置目标。

最终第 415 步诊断的 RMS 速度增量为 `0.000836106`，最大坐标分量为 `0.01184445`，夹爪附加自由度增量为 `0.000885304`，最大主拉伸为 `1.066681`。满足当前 RMS 停止条件，但仍不满足旧最大坐标分量 `0.001` 的条件。因此只能说修正模型在此输入上通过，不能把它作为旧问题的同条件修复或加速证明。旧输入来自旧模型，完整新模型轨迹必须从初态另算。

最终真实衣服短测 VelPro 两层计算时间为 `12.20 + 48.25 = 60.45 s`，Direct 细层为 `45.87 s`。这次没有总耗时优势，且运行时有单步诊断同时占用 CPU，不能据此得出性能比例。最终实体夹爪小算例中，有摩擦衣料抬升 `16.638 / 16.650 mm`，夹爪抬升 `16.667 mm`；无摩擦衣料滑落 `1.780 / 1.724 m`。这验证小算例的摩擦抓取，不替代原衣服闭爪和折叠。

## 仍然不能声称完整复现的部分

1. **PSQ 垂直初始化**已经补上 CPU 参考实现，详见上述后续记录；三层及以上动力学的全局最细代理初始化、作者并行实现及全面压力测试仍未对齐，不声称 PSQ 全部实现和性能都已复现。
2. **概率简化具体噪声参数**：当前法向标准差 0.01、位置标准差为平均边长的 0.01 倍，均显式保存。这是本项目参数；所访问论文没有给出其完整作者场景配置，不能声称逐位复现作者资产。
3. **生成任意可行层级**尚未保证：现在能提前拒绝不满足厚度的网格，没有假装自动修复。层级三层试验就是保留的反例。
4. **完整论文场景、叠衣长测、跨层级统计验证和性能实现**尚未完成。CPU 参考实现及本文短测不复现作者硬件性能；旧 GPU demo 也不作为替代证据。
5. **实体夹爪的驱动势能和几何**来自本 demo；材料、时间步、摩擦系数、接触间距、固定接触刚度都是显式场景参数，不是从论文全部场景配置恢复出来的数值。

后续验收应以逐项来源、独立公式测试、从初态的新模型实验为准，不以某个旧 demo 是否跑完倒推论文是否已复现。

旗帜 dt=0.04 s 在 PD++ 正文中明确描述的是此前 PD 2024 的四层实验，不能直接当作 PD++ 十层实验已确认的参数。本地暂采用该值并记录为推定。E=30,000 Pa、nu=0.3、rho=200 kg/m³ 也不是已恢复的作者场景参数。来源：[PD++ 论文](https://pcs-sim.github.io/pd%2B%2B/PD%2B%2B_main.pdf)。

运行入口 `scripts/run_paper_l0.py` 现支持任意单层、相邻层 VelPro 速度注入；`scripts/run_paper_hierarchy.py` 按层运行，仅在上一层完成请求窗口后进入下一层。每步检验原生状态、应变与固定点；VelPro 检验速度读回和位置未被注入改变。最细层禁止粗层预览停止。所有新运行关闭半隐式和强制更新，原生 max-axis 容差 0.001 与论文 RMS 的差异仍明确保留。

严格非下降检测发现了一个遗漏：极小 alpha 的舍入能量相等会提前结束回溯，导致原来仅在线搜索耗尽时执行的检测未触发。`--tiny-probe` 允许在 alpha<1e-8 时执行相同的三尺度非下降检验，不因 alpha 小而直接接受。旗帜因此获得 15 个已接受粗层步（0.60 s），兔子获得 43 步（0.43 s），随后均触及 Newton 上限被拒绝；这两段不是完成的论文 demo。

另提供独立的 `--preview-min-alpha 1e-8` 对照。其依据是 [PSQ Algorithm 1](https://pcs-sim.github.io/psq/psq-combined.pdf) 第 14–15 行的 alpha<gamma 停止规则：恢复当前迭代，记录 `preview_small_step`，不标成 Newton 收敛或已证实的非下降。gamma=1e-8 是本地选择，不能冒称 PD++ 作者参数；默认关闭。单位检查覆盖粗层/最细层边界、关闭状态、已收敛状态、阈值等号与无效数值。
