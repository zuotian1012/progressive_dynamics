# 稳定性复测与原夹爪抓取验证

更新：2026-11-10。本页记录旧模型的稳定性与抓取诊断；新模型公式、43 项测试及从初态的最终短测见 [PAPER_ALIGNMENT.md](PAPER_ALIGNMENT.md)。下文旧实验不能用当前默认参数直接续算。所有实验在当前 Windows 电脑执行，参考求解器使用 CPU。原衣服为 4090 顶点，作者内在映射生成 534 顶点粗层。衣服没有固定抓取点或夹爪绑定。

## 已完成的稳定性诊断

原 `pd_shirt_intrinsic_sequence` 细层第 22 步在 150 次迭代上限失败。旧重放脚本误把当前变形状态作为 IPC 的静止几何，改变了边—边接触 mollifier 阈值；因此旧 `pd_intrinsic_step21_replay` 的 141 次结果不属于相同问题对照，旧 `pd_shirt_spectral_replay` 的 40 次结果也有这一问题。主仿真初始化使用原静止几何，不受此错误影响。

修复后保留原始碰撞静止几何，并固定 IPC 与 BLAS 为单线程：

| 验证 | 结果 | 输出目录 |
| --- | --- | --- |
| 独立重建相同第 22 步三次 | 输入、状态字节、完整迭代轨迹一致；均达到 150 次上限 | `output/pd_step21_fixed_rest_repeats` |
| 保持增量问题不变，继续求解 | 再 3 次 Newton 检查达到原容差，总计 153 次 | `output/pd_step21_continuation` |
| 原轨迹从已接受断点续算，上限 200 | 两层各 30 步全部 Newton 收敛，最大主拉伸分别 1.098025 / 1.092356 以下 | `output/pd_intrinsic_sequence_resumed` |

三次重复的机器可读检查和曲线见 `pd_step21_fixed_rest_repeats/validation.json` 与 `convergence.png`；完整 30 步审计见 `pd_intrinsic_sequence_resumed/audit.json`。没有放宽 `1e-3` 速度增量容差，也没有把失败帧当作已接受状态。

这组是历史冻结偏移线搜索、严格粗层收敛的回归验证，物理时间仅 0.25 s。继承与新增计时混合，不能用于性能比较。

## 原衣服闭爪—抬升—保持实验

历史实验 `output/pd_shirt_grasp_hold` 使用非线性 PSQ 线搜索、显式粗层预览停止规则，以及原来的实体夹爪网格和控制轨迹。跟随原始控制帧 0–300，随后保持第 300 帧姿态 0.5 s；每个控制帧 2 个物理子步，步长 1/120 s，开始有 10 步静置。

| 阶段标记 | 保存状态索引 |
| --- | ---: |
| 原控制轨迹完成闭爪 | 448 |
| 抬升结束、开始保持 | 612 |
| 保持结束 | 672 |

这些索引是轨迹阶段标记，不能证明衣服已被夹住。初次运行粗层接受了 418 步，其中 318 步按预览规则停止；下一步（零起始索引 418）达到 200 次迭代上限，记录为失败。所有输出保留。

`output/pd_grasp_step418_replay` 重放该失败步：前 200 次迭代轨迹与原运行完全一致，第 274 次达到原 `1e-3` 收敛容差，速度增量为 `0.000644412`，最大主拉伸 `1.099796685`。因此已将此长测的上限提高到 500，从原已接受断点继续到新目录 `output/pd_shirt_grasp_hold_resumed`。材料、摩擦、步长、非线性线搜索及粗层预览策略未改变；未完成闭爪、保持与细层验证前，不能称为抓取成功。

最终续算结果：粗层完成 672/672 步（474 步为预览停止），细层接受 414/672 步，第 415 步达到 500 次迭代上限，已停止运行。粗层所追踪的左右衣料点抬升约 49.745 / 48.557 mm，仍不能代表细层抓取成功，也没有完整原衣服零摩擦对照。新模型从这个失败步输入进行的 87 次检查诊断同时改变了能量和收敛度量，不属于原轨迹的同条件续算。

离线测量 `scripts/measure_shirt_grasp.py` 在闭爪时选定靠近左右夹爪的衣料三角形重心点，之后跟踪同一个材料点，记录其抬升、相对实际夹爪的漂移与保持阶段下降。`--forces` 额外重建接触法向力与滞后摩擦力。这些是测量，不会增加衣服约束；没有计算到的阶段标为 pending，不读取预分配轨迹的空白尾部。最终仍需有/无摩擦匹配对照来判断抓取是否依靠摩擦；现有通过的摩擦对照仅是小型盒爪算例。

以下命令启动当前模型的新实验，不是复现上面的历史参数：

```powershell
.venv/Scripts/python.exe -m progressive.run --scene shirt --assets output/shirt_paper_2level --levels 2 --frames 331 --hold-after-frame 300 --settle-steps 10 --methods velpro --hessian coarse --max-iterations 200 --threads 1 --output output/my_shirt_grasp_hold
.venv/Scripts/python.exe scripts/measure_shirt_grasp.py output/my_shirt_grasp_hold --forces
.venv/Scripts/python.exe -m progressive.report output/my_shirt_grasp_hold --all-levels --accepted-prefix
```

不完整实验的可视化必须带 `--accepted-prefix`，只展示各选中层共同完成的前缀，图上标注未完成；不把这类动画当作完整折衣结果。

## 断点和重复性

新增 `--threads 1` 同时限制 IPC 与 BLAS，保存实际线程信息。`--checkpoint-every 1` 默认每个已接受步保存轨迹与日志。新输出目录必须为空；`--resume-from` 从源目录复制已接受前缀，重新使用原静止碰撞几何、惯性历史与实际夹爪姿态。

续算检查材料、网格、步长、控制轨迹、算法参数及库版本，允许扩展总时长、增加迭代预算或调整保存间隔。物理内核变化须显式使用 `--resume-allow-code-change`，并记录为诊断续算。异常进程未写完总清单时可用 `--resume-interrupted` 恢复，但必须先确认源进程已停止。续算结果不能作为独立性能样本，计时对照脚本会拒绝它。

当前代码启动的运行还会在每步开始检查输出目录里的 `STOP` 文件，正常保存已接受断点后停止。该功能不追溯影响用旧代码启动的进程。

历史阶段 35 项测试已通过，日志 `output/pd_stability_tests.log`。包含带摩擦的小算例中续算与不中断运行的状态逐位一致检查。

## 后续验收条件

1. 先按论文逐项验证公式与分支，再从初态重新开展新模型长测；不能把更换势能和收敛度量后的通过当成旧问题的同条件修复。
2. 完成粗、细两层的闭爪、抬升与保持，检查实际夹爪姿态、同一衣料点漂移和接触力；再运行匹配的零摩擦对照。
3. 抓取可靠后延伸到完整折叠，运行匹配 Direct 细层对照，再做空闲机器上的重复耗时测量。
4. 根据实测热点推进 GPU 实现。当前第 22 步续算的局部分析中，壳能计算约占 46%，接触约 25%，稀疏求解约 21%；只是一个局部样本，不是整段性能结论。
